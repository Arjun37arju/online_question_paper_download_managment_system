# 📄 Online Question Paper Download Management System

A secure web-based application for managing and downloading diploma question papers. The system helps educational institutions distribute question papers safely while maintaining access control and download logs.

## 🚀 Features

- 🔐 Secure Login Authentication
- 👨‍💼 Admin Dashboard
- 🏫 Principal Login
- 📥 Question Paper Upload & Download
- 📝 Download Activity Logs
- ⏰ Time-based Access Control
- 💾 MySQL Database Integration

## 🛠️ Technologies Used

- Java
- Spring Boot
- HTML
- CSS
- Thymeleaf
- MySQL
- Maven

## 📌 Project Objective

To provide a secure and efficient platform for uploading, managing, and downloading diploma question papers while preventing unauthorized access and paper leakage.
